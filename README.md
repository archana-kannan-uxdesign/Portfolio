# archanakannan.org

Portfolio website of Archana Kannan, UI/UX designer.

This folder is the published site, exported from the Claude Design canvas. It is plain HTML and CSS with no build step. Vercel serves it as-is and republishes automatically whenever this repository changes.

- `index.html`, `about.html`, `portfolio.html`, `wayatl.html`, `laya.html`, `jinx.html`: the pages
- `css/`: design-system tokens, component styles and scroll motion
- `assets/`: images, videos and fonts
- `resume/`: the résumé PDF linked from the sidebar
- `vercel.json`: clean URLs (`/about` instead of `/about.html`) and caching for assets

Edits are made on the design canvas and re-exported here, not edited by hand.
